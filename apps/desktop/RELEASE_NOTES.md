Mdit is being rebuilt with GPUI. This early version contains the initial native window and updater; the previous editor's features are not yet included.

This version starts with fresh settings. It does not import or delete the previous app's data or note files.

- macOS 12 or later; Apple Silicon and Intel builds are provided.
- Existing Tauri installations can install this release through their current updater.
- GPUI checks for future updates automatically and asks before installing. Use **Mdit → Check for Updates…** to check manually.

Before publishing this draft, edit these notes to match the implemented features and verify the Tauri-to-GPUI and GPUI-to-GPUI update paths on test installations.
